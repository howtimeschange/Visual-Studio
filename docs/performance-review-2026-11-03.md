## 发现与修复

| 优先级 | 触发与根因 | 修复及保护 |
| --- | --- | --- |
| P1 | 切换画布时，未编辑的会话也刷新 updatedAt，导致刚保存完又变脏；随后串行保存、读取项目、下载画布和聊天的完整 Base64 | 会话持久化幂等；保存与目标读取并行；保存失败仍留原页；先展示文本/元素，浏览器读取已鉴权原图。原始像素元数据和 PSD 按需完整读取保留 |
| P1 | 首页/项目列表先读所有项目及聊天 metadata，再为每个项目读全部元素；并发进入列表也会重复发请求 | 增加 summary=1，单条 D1 查询返回授权项目、元素数和一张预览；省去聊天内容和 N 个元素接口。兼容旧 API；共享/非成员/匿名权限不变；列表请求合并、空列表可缓存、过期账号回包丢弃 |
| P1 | 线上脚本已更新，但独立 workspace-layout.css 命中旧缓存，出现新逻辑配旧样式：尺寸按钮仍过宽、已加载图片误显示重试文字 | 生产构建将基础样式与工作区覆盖样式合并为同一个指纹 CSS，移除生产 HTML 的独立无版本链接；保留本地开发方式和原级联顺序。构建回归验证仅改工作区 CSS 也会改变资源指纹 |
| P2 | 四种批任务每轮分别 GET job 与 items | 复用 includeItems=1，常态一轮一个 GET；终态计数不一致时仍补读原 items，不重发模型任务 |
| P2 | 翻译、风格、测图在相同轮询快照下重绘、写本地存储，风格还重复做工作区恢复 | 无变化时跳过展示和持久化；进度/结果/错误变化和工作区切换会刷新，最终完成状态保留；旧 watcher 回包不再应用 |
| P2 | Agent 已完成时仍每 3 秒读取 runs 和全部 elements，后台页面也持续读取 | 活跃运行保持 3 秒；空闲为 15 秒；不可见视图跳过读取；回到画布/标签页立即刷新。任务资产/状态不变时复用该观察器的元素快照 |
| P2 | 每次画布编辑也触发风格历史保存，重复读写可能达 MB 级的结果缓存；保存结果重复 JSON.stringify | 风格历史内容/账号不变时不读写结果缓存；失败保存允许下次重试；普通结果保存只序列化一次 |
| P2 | 恢复大工作区同时拉取全部素材，重复资产可多次下载 | 素材 GET 共用四并发读取池；相同账号、项目、URL 的在途读取合并；完成后不长期缓存原图 Base64 |
| P2 | 管理总览的 8 项独立统计串行等待 | 并行发起独立只读聚合，保留原返回结构与权限 |
| P2 | 工作区恢复加快后，账号请求若更晚返回，首屏可能错过项目列表读取 | 账号恢复期间保留骨架屏；登录账号恢复完成且工作区就绪时补读首页/项目列表，复用请求去重；添加“账号后返回”的失败复现与回归，2 秒延迟账号的浏览器实测通过 |

画布切换反馈：目标标签立即转圈；160ms 后才出现保存/打开阶段提示，减少快速切换闪烁；原内容保留至可切换；切换期间冻结编辑，结束恢复键盘焦点。图片有加载提示及失败重试。尺寸按钮按内容收紧，空白区域不再触发弹层，设置/发送靠右，移动端保持 36px 高度。

首屏原图 URL 尚未恢复时保留加载态，不给 img 写空 src，避免把“尚未读取”误显示为“加载失败”。

项目快照仅在内存保留最多 6 个、10 秒，账号隔离、到期重新鉴权；失败不使用过期回退。预取不更新 knownElementIds，只有真正激活后才记录，避免把未见到的并发元素视为可删除对象。

## 实测与回归

### 画布切换

同一 Chrome、本地实际 Pages/D1/R2 测试环境，点击到 aria-busy=false，包含自动化往返开销；不是线上 p95：

| 往返目标 | 修改前 ms | 修改后 ms |
| --- | ---: | ---: |
| 未命名画布 | 544 | 92 |
| 交互验收画布 | 236 | 60 |
| 未命名画布 | 403 | 63 |
| 交互验收画布 | 234 | 56 |

真实含图画布往返后仍为 1340×1785 原图；两个项目草稿、原项目 3 张参考图、聊天图片和焦点保留。使用本地受控代理延迟 GET 700ms，已看到目标标签转圈和打开提示；模拟 PUT 503，原画布、未保存标题均保留并提示恢复连接。恢复代理和标题后可正常切换。没有重放历史未知任务。

### 项目列表 HTTP

使用独立本地测试账号，8 个画布，每个带 64KiB 聊天 metadata 和 20 个文本元素。实际 HTTP 对比兼容旧列表加逐项目元素读取，与新摘要接口；三组结果：

| 路径 | 请求数 | 响应正文合计 | 本地耗时 ms |
| --- | ---: | ---: | --- |
| 原列表流程 | 9 | 615942 bytes | 37 / 30 / 29 |
| 摘要接口 | 1 | 2614 bytes | 6 / 4 / 4 |

所有元素计数吻合，摘要不含 metadata。字节量是该构造数据集实测，不能外推所有生产账号或公网延迟。
